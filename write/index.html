Свои статьи

Это страница владельца. Написанное здесь появляется в разделе News и остаётся там. Google и лента новостей подхватывают готовую страницу, а не черновик.

Ключ от сайта

Один раз создайте ключ в своём GitHub, вставьте его сюда и оставьте. Он хранится только в этом браузере и даёт право менять сайт.

  1. Откройте создание ключа GitHub под аккаунтом Ibragim1996.
  2. Имя: KipFire site. Срок: на ваш выбор, можно год.
  3. Repository access: только kipfire-site.
  4. Permissions → Contents: Read and write.
  5. Создайте ключ и вставьте его ниже. Потом GitHub больше его не покажет.

Статья

Пустая строка начинает новый абзац. Строка ## Заголовок становится подзаголовком. Строка - пункт становится списком. Две звёздочки вокруг слова делают его жирным.
